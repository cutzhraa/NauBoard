# ⌨️ NauBoard

> A lightweight, clean, and fast iOS-styled Android Keyboard application built natively with Kotlin and Android SDK (headless / CLI workflow).

---

## ✨ Features

- 📱 **iOS-like Aesthetic**: Clean key layouts with rounded edges and grey-slate color scheme.
- ⚡ **Ultra Lightweight**: Minimalist footprint built directly on top of Android's official `InputMethodService`.
- 🔒 **Privacy & Security Friendly**: Zero accessibility permissions required (`AccessibilityService` free), safe from banking app security flags.
- 🛠️ **CLI Native Build**: Configured for headless environment building via standalone Gradle and Command-line tools.
